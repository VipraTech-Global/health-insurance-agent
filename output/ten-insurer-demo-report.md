Open <http://127.0.0.1:3021/demo>. Start and health-check the local stack with `bash scripts/demo_stack.sh start` from this checkout. Branch: `feat/ten-insurer-chat-demo`; nothing pushed or published off-machine.

All five unavailable flagships were recovered from official browser-rendered sources and admitted only to the H app catalogue. The frozen five unavailable slots still contribute 100/260 unavailable cases per arm. The insurer set is labelled a demo sample, not a verified top-ten ranking.

[Full scored report](search-bakeoff.md).

The 78 additional Star queries per arm retrieved packets without drafting answers. These counts do not establish semantic correctness. [Audit](paraphrase-rejections.json).
- **Winning application run:** all 260 answer-sheet cases completed: **140 answered, 120 not found**; table-heavy cases **23/65 answered**. Both query packets were complete for **12/39 Star reference cells**. This fresh run includes the recovered flagships and does not change the frozen scores. [Answers, quotations, pages, checks and omissions](application-answer-sheet.md).

Age/zone choices are manual, not inferred profile quotes. [UI evidence](demo-ui-verification.json), [price audit](premium-verification.json).

These small samples are not a speedup claim or a benchmark of the expanded release. [Samples](demo-timings-initial.json).
